# Andrés Valencia · Portafolio

Sitio personal en español: sitios para negocios, aplicaciones web, automatización e IA.

## Contenido
- `app/page.tsx`: presentación y secciones.
- `app/projects.ts`: proyectos y descripciones.
- `app/globals.css`: diseño adaptable y estilos.
- `public/images`: capturas reales con datos de demostración.

Los proyectos internos se describen sin nombres de organizaciones, información de clientes ni enlaces que las identifiquen. Las capturas inmobiliarias proceden del portafolio original y corresponden al conjunto de datos de demostración del proyecto.

## Desarrollo
`npm install`, `npm run dev`.

## Verificación
`npm run lint`, `npm run build`.

## Publicación
Se administra con Sites. La configuración del sitio está en `.openai/hosting.json`. No guardar credenciales en el proyecto.
